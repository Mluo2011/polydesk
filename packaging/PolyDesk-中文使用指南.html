PolyDesk Windows 版中文使用指南

纯本地原生 GPU 极速 Polymarket CLOB V2 交易终端 · 无需浏览器 · 私钥永不离开本机
安全保障：PolyDesk 是 100% 本地运行的桌面软件，没有任何第三方托管服务器。你的私钥仅使用 Argon2id + AES-256-GCM 加密保存在你电脑本地（%APPDATA%\polydesk\），所有订单都在本机完成 EIP-712 签名后直接发送给 Polymarket。

1. 启动软件（Windows 10 / 11）

  1. 双击运行 PolyDesk-Windows-x64.exe（单文件绿色免安装，不需要装任何额外插件或运行库）。
  2. 首次打开未签名软件时，Windows 可能会弹出蓝框「Windows 已保护你的电脑」：点击「更多信息」→「仍要运行」即可正常打开。
  3. 打开后点击右上角 中文 按钮（或按键盘 L 键），界面和所有市场名称会自动切换并翻译为简体中文。

2. 搜索市场与界面功能

  • 支持中英文混合搜索：在左侧搜索框直接输入中文（如 比特币、美联储 降息、特朗普、湖人）或英文（如 Bitcoin、Fed），按回车或点击「搜索」即可。
  • 自动中文翻译：中文模式下，市场标题、选项（是/否/队名）和关联子市场会自动翻译；鼠标悬停在标题上可同时看到英文原文，方便核对精确结算规则。
  • 纯净价格图表：默认只显示价格走势，干净不杂乱；需要技术分析时可一键开启 EMA9、SMA20、BB(20,2)、VWAP、RSI(14) 以及切换 折线 / K线。
  • 折叠市场栏：点击左上角 ◀ 可隐藏左侧市场列表，给图表和盘口更大空间。

3. 先用模拟盘免费练手（推荐）

软件默认处于 模拟盘 模式，自带 $1,000 虚拟资金，对接 Polymarket 真实实时盘口。你可以在模拟盘里零风险熟悉一键盘口下单、撤单、锁盈、条件单，完全熟练后再切换实盘。

需要重置虚拟余额时，点击右上角 钱包 / 充值 → 修改金额 → 点击 重置模拟余额。

4. 生成本地新钱包 或 导入已有私钥（如何解锁 LIVE）

点击右上角 钱包 / 充值，找到 「实盘本地加密钱包」，有两种方式：

方式 1（最简单推荐）：一键生成随机本地钱包

  1. 在 「一键生成随机本地钱包」 标签下，设一个 ≥6 位本机加密密码，点击 生成随机本地钱包。
  2. 软件会在你电脑本地随机生成全新的 Polygon 钱包地址、12 词助记词（BIP-39） 和 私钥（0x...），并自动生成专属 USDT / USDC 直充地址。
  3. 请立即离线抄写保存 12 词助记词和私钥（你随时可以把这 12 词导入 MetaMask / Rabby 提现）。

方式 2：导入已有私钥 / 12 词助记词

  • 邮箱 / Google 登录 Polymarket 官网：选 Polymarket Proxy Wallet，粘贴 66 位私钥（官网 Settings → Account → Export Private Key）和 42 位官网代理/充值地址。
  • MetaMask / Rabby 登录 Polymarket 官网：选 Polymarket Gnosis Safe，粘贴 66 位私钥（或 12 词助记词）和 42 位官网代理地址。
  • 独立热钱包（EOA）：选 EOA，直接粘贴 66 位私钥或 12 词助记词，代理地址留空即可。
安全提示：切勿导入存放大额资产的冷钱包/主钱包私钥；请使用专门的小额交易热钱包，也绝不要把助记词或私钥发给任何人。Polymarket 实盘要求年满 18 周岁且不在受限地区。

5. 如何直接转入 USDT / USDC 充值 & 如何提现

直接转入 USDT / USDC 充值（软件内自动生成官方跨链桥地址）

  1. 打开 钱包 / 充值，下滑到 「直接转入 USDT / USDC 充值 (Polymarket 官方跨链桥)」（新建钱包后已自动生成；导入钱包后点 获取 USDT/USDC 充值地址）。
  2. 直接从币安 / 欧易 OKX / Bybit / Coinbase / MetaMask / Phantom 向对应专属地址转入 USDT 或 USDC：
    • EVM 地址（0x...）：支持 Polygon / BNB Chain (BSC) / Base / Arbitrum / Optimism / 以太坊的 USDT / USDC（最低 $2–$3）
    • 波场 Tron TRC-20 地址（T...）：支持 TRC-20 USDT（最低 $2）
    • Solana 地址：支持 USDT / USDC / SOL（最低 $2）
    • Bitcoin 地址：支持 BTC（最低约 $3.6）
  3. 等待 10–60 秒，Polymarket 会自动 1:1 转为 Polygon pUSD 到账你的本地钱包，点击 刷新余额与授权 即可开始实盘交易。

提现

  • 你的资金始终在链上自己的钱包里，不由软件托管。
  • 本地生成的新钱包 / 独立 EOA：随时可将 12 词助记词或私钥导入 MetaMask / Rabby 钱包提币到交易所变现。
  • Proxy / Gnosis Safe 账户：直接打开 polymarket.com/portfolio 点击 Withdraw 提币即可。

6. 一键盘口下单、高级功能与快捷键

  • 右侧盘口（一键盘口）：
    • 点击绿色买盘深度格 = 立即以该价格买入；点击红色卖盘深度格 = 立即以该价格卖出。
    • 按住 Shift + 点击 = 强制以 Post-Only（只做 Maker 挂单）提交。
    • 点击最左/最右橙色 ×数字 = 立即撤销该价位挂单；滚轮可上下浏览价格，鼠标悬停时盘口自动冻结不乱跳。
  • 订单类型：GTC（限价挂单）、Post（只做挂单）、FAK（即时成交剩余撤单）、FOK（全部成交否则撤单）、tFOK（毫秒级定时撤单）、Sweep（多档扫盘）。
  • 高级条件单（右侧切到「高级条件单」）：支持本地微秒级触发的 止损（SL）、止盈（TP）、移动止损（Trailing Stop）、分批挂单（Scale）、定投拆单（Drip） 以及 一键锁盈（Green-Up / 抽本留利润）。
  • 多设备同步：在多台电脑/iPad 上导入同一个钱包私钥即可共用同一账户；实盘模式下软件每 4 秒自动同步全账户所有挂单、持仓和余额（包括你在网页端或其他设备下的单）。多设备同时使用时，请保持「断线防失控心跳」处于关闭状态。

7. 费率说明

PolyDesk 接入 Polymarket CLOB V2 官方链上 Builder 费率体系，费率由 Polymarket 链上实时同步并直接显示在盘口上方（下单前完全透明，无任何隐藏收费、无额外 Gas 费）。
