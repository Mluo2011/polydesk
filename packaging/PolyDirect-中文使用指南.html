PolyDirect 中文使用与充值指南

纯本地原生 GPU 极速 Polymarket CLOB V2 交易终端 · 支持 Windows / macOS / Linux / iPad · 私钥永不离开本机
安全保障（100% 本地非托管）：PolyDirect 完全在你的电脑本地运行，没有任何托管服务器。随机生成的助记词和私钥全部调用操作系统加密随机数生成器（CSPRNG）在本机生成，并以 Argon2id + AES-256-GCM 加密保存在你自己的设备中，绝不上传网络；所有订单均在本地完成 EIP-712 签名后直连 Polymarket。

1. 安装与首次打开（Windows 10 / 11）

  1. 下载并双击运行安装程序 PolyDirect-Setup.exe（无需管理员权限，会自动安装到开始菜单和桌面快捷方式）。
  2. 首次运行未签名软件时，如果 Windows 弹出蓝色提示「Windows 已保护你的电脑」：点击「更多信息」→「仍要运行」即可完成安装。
  3. 打开软件后：
    • 点击右上角 中文 按钮（或按键盘 L 键），全界面及所有市场标题会自动切换为简体中文。
    • 点击右上角 浅色 / 深色 按钮，可随时自由切换浅色模式 / 深色模式并自动记住偏好。

2. 浏览与搜索全站市场

  • 直接点击任意市场卡片即可打开：点击左侧市场卡片的任意位置（标题、价格或空白区域）即可切换市场；点击左上角 ★ 可加入自选收藏。
  • 支持中英文搜索全站市场：搜索框可直接输入中文（如 比特币、美联储、特朗普、NBA）或英文关键词；列表底部点击「加载更多市场 (+100)」可继续翻页加载 Polymarket 全站活跃市场。
  • 顶部实时资产栏：顶部直接展示当前 总资产（Portfolio）、可用余额（Cash） 与 浮动盈亏（P&L）。
  • 先练手再实盘：软件默认处于 模拟盘（内置 $1,000 模拟金，对接真实实时盘口），零风险熟悉后再切实盘。

3. 新建随机本地钱包 或 导入已有私钥

点击右上角蓝色 + 充值 / 钱包 按钮，有两种方式开启 实盘：

方式 A（推荐，最省事）：一键生成随机本地钱包

  1. 选择 「一键生成随机本地钱包」，设置一个 ≥12 位的本机加密密码（旧版本已创建的 ≥6 位密码加密库仍可正常解锁），点击 生成随机本地钱包。
  2. 软件会在你电脑本地随机生成一个全新的 Polygon 钱包地址、12 词助记词（BIP-39） 和 私钥（0x...），并自动为你生成专属的 USDT / USDC 直充地址。
  3. 请立刻用纸抄写保存这 12 个助记词和私钥（不要发给任何人，也不要截图上传云盘）。以后随时可在 MetaMask / Rabby 中用这 12 个词恢复钱包或提现。
  4. 如果日后想再次查看备份，在钱包窗口输入你的加密密码点击「查看助记词/私钥」即可。

方式 B：导入已有私钥或 12 词助记词

  • Polymarket 官网（邮箱 / Google 登录）：钱包类型选 Polymarket Proxy Wallet，填入 66 位私钥（官网 Settings → Account → Export Private Key）及官网的 42 位充值/代理地址。
  • Polymarket 官网（MetaMask / Rabby 登录）：钱包类型选 Polymarket Gnosis Safe，填入私钥或 12 词助记词及官网代理地址。
  • 独立冷/热钱包（EOA）：钱包类型选 EOA，填入私钥或 12 词助记词，代理地址留空即可。
安全提醒：请只用专门的小额交易钱包，不要导入存放大额长期资产的主钱包。Polymarket 实盘要求年满 18 周岁且遵守当地法规。

4. 如何直接转入 USDT / USDC 充值 & 如何提现

直接转入 USDT / USDC 充值（官方跨链桥自动 1:1 转换）

  1. 在 + 充值 / 钱包 窗口下滑到 「直接转入 USDT / USDC 充值 (Polymarket 官方跨链桥)」（新建钱包会自动加载；导入钱包后点 获取 USDT/USDC 充值地址）。
  2. 从币安（Binance）、欧易（OKX）、Bybit、Coinbase、MetaMask 或 Phantom 直接提币 USDT 或 USDC 到你的专属充值地址：
    • EVM 地址（0x...）：支持 Polygon / BNB Chain (BSC) / Base / Arbitrum / Optimism / 以太坊的 USDT / USDC（最低 $2–$3）
    • 波场 Tron TRC-20 地址（T...）：支持 TRC-20 USDT（最低 $2）
    • Solana 地址：支持 USDT / USDC / SOL（最低 $2）
    • Bitcoin 地址：支持 BTC（最低约 $3.6）
  3. 建议首次先用 $5–$10 小额测试。等待约 10–60 秒，官方跨链桥会自动 1:1 换成 Polygon pUSD 到账你的钱包，随后点击 刷新余额与授权 即可看到余额并直接下单！

如何提现

  • 你的钱始终在你自己的链上钱包里，不由软件托管。
  • 本地生成的新钱包 / EOA：随时把 12 词助记词或私钥导入 MetaMask / Rabby，直接把 Polygon 上的 USDC/pUSD 提币回交易所即可。
  • 官网 Proxy / Safe 钱包：直接登录 polymarket.com/portfolio 点击 Withdraw 提现。

5. 下单教程 & 什么是「1 份」？

什么是「1 份」（1 share）？

Polymarket 上买卖的单位是份（shares）：每 1 份在结果猜对时固定兑付 $1.00，猜错则归 $0.00。

  • 举例：如果「是」当前价格是 40¢（$0.40），你买入 $20，就会得到 50 份；如果最终结果是「是」，这 50 份结算拿到 $50.00（净赚 $30.00）。
  • 你也可以随时在结果出来前提前卖出（比如涨到 65¢ 时卖出这 50 份，直接落袋 $32.50）。

右侧三种下单模式

  • 快捷买卖（默认，和 Polymarket 官网一样简单）：选择 买入 / 卖出 → 选 是 / 否 → 输入金额（或点 +$1 / +$10 / +$50 / +$100）→ 一键点击大按钮 「立即买入 / 立即卖出」 即可成交，支持市价和限价。
  • 专业盘口（Ladder）：直接点绿色买盘格挂买单、点红色卖盘格挂卖单；按住 Shift + 点击 强制只做 Maker 挂单；点击橙色 ×数字 一键撤单；支持 GTC / Post / FAK / FOK / tFOK / Sweep。
  • 条件单（Pro）：支持本地微秒触发的 止损（SL）、止盈（TP）、移动止损（Trailing）、分批阶梯挂单、以及 一键锁盈（Green-Up / 抽本留利润）。

6. 自动更新与多设备同步

  • 软件内一键自动更新：有新版本发布时，软件顶部会出现绿色更新提示按钮，或在 「设置」 中点击「检查更新」→「立即下载并更新」。更新前会强制校验 SHA-256 哈希，验证通过后自动替换并重启，无需重新下载安装包。
  • 多设备同步：在多台电脑或 iPad 上导入同一个钱包即可共用同一账户；实盘模式下软件每 4 秒自动同步全账户所有挂单、持仓和余额（多设备同时使用时，请保持「断线防失控心跳」处于关闭状态）。
